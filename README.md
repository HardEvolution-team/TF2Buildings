# TF2 Buildings Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **TF2 Sentry and TF2 Dispenser** by pitman-87.

- Original: http://www.minecraftforum.net/topic/334760-125smp-ssp-team-fortress-2-teleporter-sentry-dispenser/
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.33.0+

This port contains **no original assets**. Put your own copy of the original jar (`TF2Sentry-1.7.10.jar and TF2Dispenser-1.7.10.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
